# CAKE

> CAKE (stylized CAKE, ridecake.com) is a Stockholm, Sweden based maker of premium,
> lightweight, high-performance electric motorcycles and mopeds — commuter models
> (Makka, Osa), off-road bikes (Kalk, Bukk) and the :work utility line for last-mile
> delivery and professional fleets. CAKE sells direct to consumers and through dealers.
> CAKE markets a "CAKE API" that lets fleet owners pull vehicle data and controls into
> their own fleet software via the CAKE Connect connectivity module, but publishes no
> developer portal, no API reference and no machine-readable specification for it.
> This file was generated by API Evangelist from the public CAKE surface; CAKE does not
> serve an llms.txt of its own (https://ridecake.com/llms.txt returned HTTP 500).

## API surface

- [CAKE API (undocumented)](https://ridecake.com/en-US/food-delivery): Referenced on CAKE's own :work / delivery pages — "All vehicle data and controls can easily be integrated via the CAKE API to third party software." No public base URL, reference, or specification. Access is only reachable through the general contact and partner forms.
- [CAKE Connect](https://ridecake.com/en-US/terms-and-conditions-of-cake-app): The mobile app and connectivity platform the API sits behind — GPS tracking, battery status, ride statistics, lock/unlock, ride-mode tuning and over-the-air firmware updates.
